## Scope and inclusion rule

I used the current runtime code/assets as source of truth. "Large articulated fauna" means an entry in `public/assets/generated/articulated-creatures.parts.json` with multi-part runtime anatomy and manifest `radius >= 58`, or a code-signature large threat. This uses the code's own large-threat evidence where available: `isLargeArticulatedThreatManifest` treats signature IDs plus epic/legendary min-biome-3 radius-58+ articulated creatures as large threats (`src/helpers.ts:100`, `src/helpers.ts:112`). I also include Abyssal Mandible Bobbit because it is radius 58, spawned as an articulated burrow creature, and has bespoke large-creature behavior.

Important runtime note: the loader replaces the fallback with `public/assets/generated/articulated-creatures.parts.json` (`src/articulated.ts:261`). Normal gameplay spawns only accepted or legacy runtime IDs (`src/articulated.ts:312`, `src/articulated.ts:331`); prototype/playtest mode (`?playtest=1`, `prototypeThreats`, or `threats=prototype`) enables the prototype-only manifest entries and uses larger early-biome budgets (`src/articulated.ts:241`, `src/articulated.ts:236`).

## Spawn system summary

Depth conversion: manifest depth bands are meters converted by `scaledDepthPx(value) = value * deepScale`, with `deepScale = WORLD_H / 156` (`src/constants.ts:5`, `src/constants.ts:10`, `src/helpers.ts:3324`). With `WORLD_H = 420`, deepScale is about 2.692 px per meter. The world is 104 x 420 tiles, tile size 24 px (`src/constants.ts:3`, `src/constants.ts:4`).

Population flow:

- `generateWorld` resets entities, reserves bobbit and signature encounter areas, then calls `populateArticulatedCreatures()` and `populateBobbitArticulatedThreats()` after fish/flora/special rooms (`src/scene-worldgen.ts:13`, `src/scene-worldgen.ts:60`, `src/scene-worldgen.ts:71`).
- Articulated spawn budgets are normal `{1:4, 2:6, 3:8, 4:10}` and prototype `{1:8, 2:8, 3:9, 4:10}` (`src/articulated.ts:236`).
- Bobbits are reserved first and subtract from the open articulated budget: biome 2/3 reserve 1 burrow, biome 4 reserves 2 (`src/scene-worldgen.ts:351`, `src/scene-articulated.ts:536`, `src/scene-articulated.ts:712`).
- Non-bobbit articulated creatures are filtered by `state.biome >= manifest.minBiome`, spawn-enabled mode, and not bobbit; sorted by signature priority, then runtime mode, then ID; each gets `min(manifest.spawn.count, remainingBudget)` (`src/scene-articulated.ts:712`).
- Signature IDs prefer reserved encounter slots: bobbit burrows, gulper arena, reliquary route, and skulk side tunnels (`src/scene-articulated.ts:506`, `src/scene-articulated.ts:523`, `src/scene-worldgen.ts:477`).
- Non-reserved spawns use random open water in the declared depth band, up to 90 attempts, avoiding encounter reservations; if no clear pose is found, the code carves a spawn pocket (`src/scene-articulated.ts:733`, `src/scene-articulated.ts:736`, `src/scene-articulated.ts:751`, `src/scene-worldgen.ts:1946`).

## Shared behavior and rendering

Default articulated behavior is inferred from ID unless overridden: rays/boxers/mantis are `charger`, eel/serpent/gulper/maw are `serpent`, coral/shelf/anemone/harp and sponge/battery/crown are `territorial`, everything else defaults to `ambusher` (`src/articulated.ts:251`). Combat defaults set detection/leash/attack/lunge/grab values by behavior; manifest combat overrides can change them (`src/scene-articulated.ts:41`). All included non-bobbit creatures are hostile by default unless their manifest says passive (`src/articulated.ts:400`).

General non-bobbit AI: patrols around home with sine offsets; if hostile, not at boat, player is in detection range plus a biome bonus, and the creature is inside leash range, it enters stalk and later lunge when inside attack range (`src/scene-articulated.ts:1173`). Lunge uses higher steering and behavior-specific speed scale; grab-capable creatures enter grab on a dangerous-part hit (`src/scene-articulated.ts:1192`, `src/scene-articulated.ts:1213`, `src/scene-articulated.ts:1780`). A grab pulls the player/sub toward the bite anchor, drains hull and oxygen, and releases on timer/struggle/stun/knife (`src/scene-articulated.ts:1726`).

Damage/contact: dangerous parts are jaws, mandibles, teeth, claws, stingers, spikes, saws, hooks, harpoons, sharp fins, or the configured bite part (`src/scene-articulated.ts:381`). Contact damage is `round((12 + biome*2.6 + creature.radius*0.18 + impact*0.012) * strike * damageMultiplier) - suit`, minimum 5 (`src/scene-articulated.ts:1750`). Large code-signature threats resist the life cutter: it pushes/aggros them and reports armored hide instead of damaging them (`src/scene-combat.ts:341`, `src/scene-combat.ts:356`). Parts can be damaged, crippled, detached, and can disable grab/bite if a jaw/bite part is lost (`src/scene-articulated.ts:664`, `src/scene-articulated.ts:1817`).

Sonar: a sonar ping attracts articulated creatures within `SONAR_ATTRACT_RADIUS + creature.radius`, raises aggro to at least 5.2, nudges home toward the player, and marks them as predator contacts (`src/scene-sonar.ts:42`, `src/scene-sonar.ts:68`).

Rendering/articulation: every included creature is rendered as sprites per manifest part and optional socket overlays (`src/articulated.ts:400`). Runtime motion updates body/tail spine springs, fin/jaw soft rotation, lunge jaw/mandible opening, socket overlays, terrain contact, detached part tumbling, and large-threat ripple turning for serpent/gulper/crownmaw/skulk/reliquary-wyrm (`src/scene-articulated.ts:33`, `src/scene-articulated.ts:1308`, `src/scene-articulated.ts:1447`, `src/scene-articulated.ts:1499`, `src/scene-articulated.ts:1647`). Runtime display radius is manifest radius * `ENTITY_SCALE` (0.72) (`src/articulated.ts:429`, `src/constants.ts:11`).

## Design notes / likely follow-ups

- Normal gameplay large-articulated density is concentrated in biomes 3 and 4; biome 1 has none and biome 2 has only bobbit burrow ambushes. That appears intentional from the legacy runtime ID set, but it means most large articulated assets are currently prototype-only or budget-starved.
- Prototype mode has many large entries sharing generic 5-part scaffold anatomy and generic hostile behavior. Several plant/colony-like entries are treated as mobile hostile creatures because their manifests do not mark them passive.
- Budget/order starvation is real: many radius-58+ prototype manifests are spawn-enabled in principle but never reached with the current sorted population loop and biome budgets.
- Abyssal Mandible Bobbit is the most bespoke behavior and spawn system. It is also the only normal large articulated fauna in biome 2.
