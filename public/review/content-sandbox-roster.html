Content Sandbox Roster

Quick launch surface for all 20 target threats. Each row must provide source, runtime, paired-diver preview, and visual-check commands before the content route can be considered mechanically reviewable.

Previewable does not mean accepted. Human source approval and threat acceptance remain separate gates.
20/20 sandbox-ready 20 runtime previews 20 source previews 20 paired runtime 20 paired source 0 accepted threats

Commands

  • npm run sandbox:index
  • npm run content:sandbox-roster
  • npm run content:sandbox-roster-check
  • npm run sandbox:preview -- --id <entity-id> --with diver --serve --open --visual
  • npm run sandbox:visual -- --ids <entity-id> --with diver
